비밀번호 대신 GitHub 토큰으로 인증합니다. 이 저장소에 쓰기 권한이 있는 토큰이 없으면 아무도 저장할 수 없습니다.

  1. GitHub 토큰 만들기를 엽니다.
  2. Repository access는 Only select repositories를 고르고 ai-shadow-slides만 선택합니다.
  3. Permissions → Repository permissions → Contents를 Read and write로 설정합니다.
  4. 만료일은 짧게(예: 30일) 정하고 만든 뒤 나온 토큰을 아래에 붙여 넣습니다.

토큰은 이 브라우저 탭의 임시 저장소에만 두고, 탭을 닫으면 지워집니다. 서버로 보내지 않고 GitHub로만 전송합니다.

슬라이드

가리기는 그림 위에 검은 상자를 그려 이미지 파일 자체에 새겨 넣습니다. 화면 위에 덮는 방식이 아니라서 원본 파일에서도 사라집니다.
다만 GitHub는 이전 버전을 기록으로 남기므로, 이미 공개된 개인정보는 저장소 기록 정리가 따로 필요합니다. 중요한 정보라면 알려 주세요.

· 번호: 보기 화면에 나오는 순서로 매번 새로 매겨집니다. 삭제·숨김을 하면 뒤쪽 번호가 바로 앞당겨지고, 슬라이드 그림 속 번호도 이 번호로 바뀌어 보입니다.
· 숨김 체크: 보기 화면에서 그 장을 건너뜁니다(파일은 남음). 아래쪽 저장을 눌러야 반영됩니다.
· 가리기: 마우스로 드래그해 상자를 그린 뒤 이미지에 적용합니다.
· 삭제: 이미지 파일을 저장소에서 지웁니다. 누르는 즉시 반영됩니다(저장 버튼 불필요).
